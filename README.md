\# Automation Exercise – E-Commerce Testing



\## Project Overview

This project covers Manual Testing, Automation Testing, API Testing, and AI-based Testing of the Automation Exercise e-commerce website.



\## Testing Types

\- Manual Testing

\- Selenium Automation Testing

\- API Testing

\- AI Testing using Testim



\## Tools \& Technologies

\- Java

\- Selenium WebDriver

\- TestNG

\- Maven

\- Postman

\- Rest Assured

\- Testim

\- Git

\- GitHub

\- Jenkins



\## Project Scope

\- Login

\- Products

\- Product Search

\- Product Details

\- Cart

\- Checkout

\- Payment

\- Order Confirmation

\- Logout



\## Automation Framework

The automation framework is developed using Java, Selenium WebDriver, TestNG, Maven and Page Object Model (POM).



\## API Testing

API testing was performed using Postman for manual API testing and Rest Assured with Java and TestNG for automation.



\## AI Testing

AI-based test automation was performed using Testim for login and dashboard validation.



\## CI/CD

Jenkins CI/CD integration is in progress.
